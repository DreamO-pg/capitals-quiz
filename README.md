# Столицы — Telegram Mini App

Игра-викторина про столицы стран. Личная: без рекламы, аккаунтов, аналитики и бэкенда.
Статика на GitHub Pages, прогресс — в `CloudStorage` телеграма.

## Стек

- Vite 6 + TypeScript + React 18, сборка в `dist/`
- Telegram Mini Apps SDK — скриптом в `index.html`, всё через `window.Telegram.WebApp`
- Шрифты (Literata, Golos Text) — в бандле через `@fontsource`, внешних запросов нет
- Единственное, что грузится извне в рантайме, — тайлы OpenStreetMap на экране ответа
  (появятся на этапе 5)

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173 — работает и без телеграма
npm run build      # сборка в dist/
npm run preview    # посмотреть собранное
npm run typecheck  # tsc без эмита
```

Вне телеграма игра работает на `localStorage`, без тактильного отклика и без системной
кнопки «назад». Падать при этом не должна — если упала, это баг.

## Деплой на GitHub Pages

1. Создать репозиторий и запушить:

   ```bash
   git remote add origin git@github.com:<username>/capitals-quiz.git
   git push -u origin main
   ```

2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
   Дальше `.github/workflows/deploy.yml` собирает и публикует на каждый push в `main`.

3. Адрес страницы: `https://<username>.github.io/capitals-quiz/`

### Имя репозитория и base path

`base` в [`vite.config.ts`](vite.config.ts) задан константой `REPO = 'capitals-quiz'`.
Если репозиторий назван иначе — поменять её, иначе на Pages не подхватятся ассеты
(белый экран, 404 на `assets/*`).

Исключение: репозиторий вида `<username>.github.io` живёт в корне — тогда `REPO` заменить
на пустую строку и убрать слэши, `base: '/'`.

## Подключение к боту (BotFather)

1. `/newbot` — создать бота, забрать токен (никуда его в код не кладём, он не нужен:
   бэкенда нет).
2. `/newapp` → выбрать бота → название, описание, картинку 640×360
   (`brand/app-card-640x360.png`) → **Web App URL**:
   `https://<username>.github.io/capitals-quiz/`
   Короткое имя даст прямую ссылку `t.me/<bot>/<short_name>`.
3. Чтобы игра открывалась кнопкой в чате: `/mybots` → бот → **Bot Settings → Menu Button →
   Configure menu button** → тот же URL и подпись кнопки.

Аватар бота: `/setuserpic` в BotFather, файл `brand/bot-icon-512.png`.

После смены URL или пересборки телеграм может отдавать старую версию из кеша: в клиенте
долгий тап по мини-приложению → «Перезагрузить», либо закрыть и открыть заново.

## Пересборка базы стран

`src/data/countries.ts` собран скриптом, руками его не правят:

```bash
node scripts/build-countries.mjs
```

Источники — без ключей и регистрации:

| Что | Откуда |
|---|---|
| названия ru/en, сухопутные границы, регион, членство в ООН | `mledoze/countries` |
| русские названия столиц, координаты | Wikidata SPARQL |
| bbox страны | Natural Earth 10m |

Скачанное кешируется в `.cache/` (в git не попадает) — повторный прогон идёт офлайн.
Чтобы обновить данные, удали кеш.

Редакторская часть — в [`scripts/curation.mjs`](scripts/curation.mjs): выбор столицы у
стран с несколькими, уровень сложности, омывающее море, пояснения. Только это и правится
руками.

Скрипт печатает предупреждения — их надо читать. Он сверяет выбранную столицу с
mledoze и ругается на расхождения: так поймался переезд столицы Экваториальной Гвинеи,
который Wikidata уже засчитала, а справочники ещё нет.

## Структура

```
src/
  telegram/       обёртка над WebApp SDK + фолбэк на браузер
  theme/          токены палитры, радиусов, шрифтов
  hooks/          вьюпорт, системная кнопка «назад»
  components/     оболочка экрана, дальше — флаг, карта, варианты
  screens/        главная, вопрос, ответ, итог, статистика
  data/           countries.ts — 195 стран (этап 2)
  engine/         подбор вопросов, Лейтнер, хранилище (этап 3)
```

## Что уже сделано

- **Этап 1** — каркас: сборка, обёртка над SDK, токены темы, шрифты, пустые экраны,
  деплой.
- **Этап 2** — данные: 195 стран с координатами столиц, bbox, соседями, морями,
  сложностью и пояснениями к спорным столицам.
- **Этап 3** — движок: подбор вопросов, дистракторы из своего региона, система Лейтнера,
  хранение прогресса в CloudStorage с фолбэком на localStorage.
- **Этап 4** — экран вопроса и экран ответа: флаги, состояния вариантов, строка контекста.
- **Этап 5** — карта: Leaflet и тайлы OpenStreetMap, силуэт страны, врезка-глобус,
  запасная карта из бандла на случай отсутствия сети.
- **Этап 6** — итог раунда кольцом, статистика, работа над ошибками, режим
  «страна на карте».
- **Этап 7** — полировка: анимации, тактильный отклик, предложение добавить на
  экран «Домой», картинки для бота.

Игра собрана целиком.

### Итог вопроса

Итог показывается панелью поверх экрана вопроса, а не отдельной страницей: вопрос
остаётся виден сверху, связь «страна → где она на карте» не рвётся переходом.
Паузы перед показом нет — экран не сменяется, держать её незачем.

Панели нужен `z-index` выше 1000: столько Leaflet даёт своим контролам, и подпись
карты из вопроса иначе всплывает поверх кнопки «Дальше».

### Картинки

`node scripts/build-icons.mjs` кладёт в `brand/` аватар бота, карточку для `/newapp`
и favicon. Знак — тот же глобус, что стоит врезкой на экране ответа.

Конвертеров SVG в системе нет, а тянуть нативный модуль ради трёх картинок незачем:
скрипт растеризует фигуры сам и кодирует PNG встроенным zlib. Сглаживание — через
сверхдискретизацию, рисуем вчетверо крупнее и усредняем.

### Режим «страна на карте»

Четыре пронумерованные точки, отвечаем нажатием прямо по маркеру. Дистракторы тут
подбираются не так, как в остальных режимах, — им задан разброс:

- **не ближе 2.5°** друг к другу, иначе маркеры накладываются: столицы Ватикана и
  Италии стоят в двух километрах;
- **не дальше 22°** от ответа, иначе кадр раздувается. Минск и Рейкьявик оба «Европа»,
  но с таким дистрактором карта раскрывается от Гренландии до Африки, и уже Минск с
  Киевом не различить.

Если подходящих соседей нет (Океания), предел разлёта ослабляется в несколько заходов.

Долготы четырёх точек приводятся к одной системе: Тихий океан пересекает антимеридиан,
и по сырым числам между Палау и Тонга получается 309° вместо настоящих пятидесяти.

### Карта

Геометрию собирает `node scripts/build-shapes.mjs` (запускать после `build-countries.mjs`):

- `src/data/shapes.ts` — упрощённые контуры 195 стран, заливка на карте;
- `src/data/world.ts` — грубый контур суши для врезки-глобуса.

Оба грузятся динамическим импортом — на главном экране геометрия не нужна. Точность
упрощения подобрана под то, что реально видно: страна занимает около половины ширины
виджета, детали мельче span/160 не различить.

Кадр считает `src/engine/frame.ts`: рамка страны, раздвинутая в 2.2 раза, но поле вокруг
ограничено двенадцатью градусами. Без ограничения Россия получала кадр в 336° — планету
целиком и ещё сверху.

Зум обязательно дробный (`zoomSnap: 0`). По целым ступеням `fitBounds` округляет вниз, и
кадр вроде Саудовской Аравии раскрывается вдвое шире нужного — на таком масштабе
OpenStreetMap уже не подписывает ни страны, ни моря.

### Флаги

Лежат в `src/assets/flags` — ровно 195 штук, их кладёт туда тот же
`build-countries.mjs`. Vite инлайнит их в бандл как data-URI, поэтому за флагом не
уходит ни одного сетевого запроса.

Глоб прямо по `node_modules/country-flag-icons` тянул все 267 флагов пакета, включая
флаги территорий с детальными гербами — они весят в разы больше и в игре не нужны.

### Как устроен подбор вопросов

Раунд — десять вопросов: примерно шесть на повторение, четыре на новое. Слоты повторения
делятся между слабыми странами и дозревающими: если отдавать всё слабым, страны из третьей
коробки никогда не всплывают и не дозревают.

Неправильные варианты берутся из того же региона и по возможности того же тира — случайные
страны с разных континентов делают вопрос бессмысленно лёгким.

«Только простые» в узком регионе — фильтр не жёсткий: простых стран в Африке девять, в
Океании две, на раунд не хватает. Если простых мало, подмешивается средний тир, в крайнем
случае берётся регион целиком.
